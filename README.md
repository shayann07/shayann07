# Hi, I'm Shayan

Kotlin Multiplatform developer from Pakistan. I build apps that share their logic and UI across Android, iOS and desktop with Compose Multiplatform, and lately I've been spending a lot of time on graphics and shaders.

My main open-source project is [liquidglass](https://github.com/shayann07/liquidglass), a Liquid Glass effect for Compose: real refraction, dispersion and rim lighting in one shader, applied with a single modifier.

## Apps I've shipped

- [Upscaly](https://upscaly.shayxo.dev): AI photo upscaling that runs entirely on your device
- [Medly](https://play.google.com/store/apps/details?id=com.medly.reminder): pill reminders with prescription scanning
- [EyeIQ](https://play.google.com/store/apps/details?id=com.eyeiq.visiontest): eyesight and vision tests
- [UrduCanvas](https://play.google.com/store/apps/details?id=com.webscare.urducanvas): Urdu design editor
- [Urdu Speech to Text](https://play.google.com/store/apps/details?id=com.webscare.urduspeechtotext): voice transcription in Urdu
- [Speedometer GO](https://play.google.com/store/apps/details?id=com.webscare.speedometer): offline GPS speedometer and trip tracking
